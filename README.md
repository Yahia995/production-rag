# Production RAG Platform

A production-oriented Retrieval-Augmented Generation (RAG) platform designed to
demonstrate the complete lifecycle of a knowledge system:

document ingestion → retrieval → reranking → generation → citations → evaluation → observability.

## Status

Phase 0 — Design and project bootstrap.

## Python

Python 3.11.14

## Project Goal

The project aims to evolve beyond a basic semantic search system into a
production-oriented RAG platform covering:

- document ingestion
- parsing and chunking
- embeddings
- dense and sparse retrieval
- hybrid search
- reranking
- metadata filtering
- query transformation
- conversational retrieval
- grounded generation
- citations
- evaluation
- observability
- testing
- security
- Dockerized deployment

The architecture and implementation will be developed incrementally.
